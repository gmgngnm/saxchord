# SaxChord — サックスのコード＆運指クイズ

サックスのソロ（アドリブ）練習のために、**コードの構成音を覚える → その場で運指を確認する → 実際に吹いて確かめる**までを 1 画面で回すための静的 Web アプリ。ビルド不要、`index.html` を開くだけで動く。

## なぜ作ったか

既存のものは役割が分かれていて、管楽器奏者がいちばん詰まる「実音 ⇄ 記譜」の変換をまたいでくれない。

| 必要なこと | 既存の代表例 | 足りない点 |
| --- | --- | --- |
| コード構成音のクイズ | Chord Tone Training / ChordIQ / コードクイズ | 答えがピアノ鍵盤。E♭ 管の運指に繋がらない |
| 運指表 | Saxophone Fingering Chart など | クイズではなく引くだけ |
| 音程のマイク判定 | Saxophone Fingering Tuner ほかチューナー全般 | 「いま吹くべき音」と繋がっていない |

このアプリはその 3 つを 1 本に繋ぐ。

## できること

- **コード → 構成音**：コード名を見て 12 音から構成音をすべて選ぶ。
- **度数クイズ**：「B♭7 の ♭7 は？」をアドリブ中の速さで答える練習。
- **構成音 → コード名**：並んだ音からコード名を当てる。
- **運指クイズ**：運指図 → 音名、音名 → 運指の両方向。
- **吹いて答える（マイク）**：コードトーンを下から順に吹くと、マイクで音程を検出して 1 音ずつ ✓ が付く。全部吹けるとコードトーンが「たたたん」と通しで鳴る（フレーズとして耳に残すため）。
- **音を隠す**：吹いて答えるモードで、コード名だけを出して構成音も運指も見せない。自分で考えて吹く練習用。ヒントで表示でき、吹けた音から順に見えるようになる。
- **チューナー / 音当て**：吹いた音の実音・セント・その音の運指を表示。
- 答え合わせは**必ず運指図つき**。度数・記譜音・実音を並べて表示する。
- **使い方ページ**：クイズ画面の右上「?」から開く。画面の各表示が何を意味するかと、運指図のキー名つきの図が載っている。
- 苦手なコード／ルートほど出題されやすくなる（成績画面で確認できる）。
- 楽器は **アルト・テナー・ソプラノ・バリトン**。オフラインでも動く（PWA）。

## 譜面（C譜 / 移調譜）

楽器（アルト・テナー・ソプラノ・バリトン）と譜面は、**画面右上の楽器バッジをタップ**すると、どの画面からでも 1 タップで切り替えられる（設定画面にも同じものがある）。

- **E♭譜 / B♭譜（自分のパート譜）**：譜面に書かれたコードをそのまま吹く。吹奏楽やバンドの移調済みパート譜がこれ。
- **C譜（実音・イン C）**：ピアノ・ギターと同じ実音で書かれたコード。リアルブックの原曲キーや iRealPro の C 表示がこれ。自分で移調して吹くので、アルトなら「C譜の C△7 → A C♯ E G♯ を吹く」という訓練になる。

楽器に「移調なし（C 管）」は置いていない。テナーを吹く人が C譜 を読みたくてそれを選ぶと、実音そのままの運指が出て**実際には 1 音低く鳴ってしまう**ため。**C譜を読みたいときは楽器は自分の楽器のままで「譜面」を C譜 にする**。運指はあなたの楽器のものが出る。

運指図はどのモードでも**あなたが実際に押さえる指**で表示し、カードの下に記譜音と実音を並べて出す。

## マイク判定について

- Web Audio API の生波形から NSDF（McLeod 法の簡易版）で基本周波数を推定する。サックスは倍音が強くオクターブを取り違えやすいので、自己相関のピークは「最大値の 0.85 倍を超える最初のピーク」を選ぶ。
- 判定はピッチクラス一致（オクターブは不問）＋ ±45 セント以内が約 0.2 秒続いたら合格。
- 基準ピッチは設定で変更できる（初期値 442Hz）。

### 誤検出を防ぐ

判定は感度スライダーとは別に、次の条件をすべて満たしたときだけ合格にする。感度を上げても、部屋の雑音や前の音の余韻で勝手に進まないようにするため。

- 自己相関 0.62 以上（サックスの音は倍音がそろっていて高く出る。雑音は低い）
- 目標の音がいったん「鳴っていない」状態を挟んでから数え始める
- 音が切り替わった直後 350ms は判定しない
- ピッチクラス一致かつ ±45 セント以内が 6 フレーム（約 0.2 秒）続く

それでも誤って進んだときは、**音名のチップをタップするとその音に戻れる**。

### 感度

「大きく吹かないと反応しない」ときは感度を上げる。**吹いて答える／チューナー／設定**の各画面に感度パネルがある。

- **音量メーター**：いまマイクに入っている音量。縦の赤線がしきい値で、バーがそれを越えて緑になれば拾えている。反応しない原因が「音量が届いていない」のか「音程が取れていない」のかを、これで切り分けられる。
- **1〜7 の段階**：しきい値（RMS）と、音程が取れたと見なす自己相関の下限をまとめて動かす。**6・7 は最高感度**で、マイクが遠いときや音量が小さいとき用。雑音にも反応しやすくなる。
  （NSDF は振幅に依存しないので、しきい値さえ下げればごく小さい音でも音程は取れる。ゲインを上げる必要はない。）
- **自動で合わせる**：周囲の雑音を 1.5 秒測り、その少し上にしきい値を置く。**測定中は吹かないこと**。

判定が渋いときは感度を上げ、雑音で勝手に進んでしまうときは下げる。設定は保存される。
- **HTTPS（または localhost）でないとマイクは使えない**。ブラウザの仕様。
- Web フォントは JS から後入れし、描画にも `load` イベントにも関わらせていない。CDN が遅い・届かない練習場所でも、代替フォントでそのまま動く（Service Worker の登録も `load` を待たない）。

## 鳴らす音

Web Audio でサックスの音を組み立てている。倍音の並びを実測に近づけた波形（2〜4 倍音が強く以降なだらかに減る）を作り、860Hz と 1.85kHz のフォルマントであの芯を出し、吹き始めにローパスを開いて息が入る感じを付け、少し遅れてビブラートをかける。アタックには短い息の音を混ぜている。

`node test.mjs` では OfflineAudioContext で実際にレンダリングし、音程・倍音の並び・立ち上がり・減衰・音割れの有無を検証している。

## 配色

設定の「配色」で 4 案から選べる（藍＝既定／真鍮／朱／黒板）。**ライトのみ**で、端末のダークモードには追従しない。譜面台の上でも、明るい練習室でも、見え方を一定にするため。

## 運指図

`saxfinger.png` そのものを使っている。背景を抜いてアルファだけにしたもの（`saxfinger-mask.png`）を CSS マスクにして配色テーマの色で塗り、その下に押さえるキーだけ色を敷く。原画の形と位置には一切手を加えていない。

原画は運指を表すのに要るキーが揃っていない。左手小指のテーブル（G♯・低 C♯・低 B・低 B♭）、右手小指（低 E♭・低 C）、F♯ キーは描かれておらず、サイドキー（側面 E・C・B♭、ハイ F♯）は 3 つが 1 つの塊になっている。これらは図の下に「＋ 低B♭（左小指）」のように文字で補う。

マスクの作り方（原画を差し替えるとき）：背景色 197 と描線 112 の差をアルファに写し、RGB は白で固める。アンチエイリアスもそのまま残るので輪郭はなめらかなまま、色だけテーマに追従する。

## 運指データについて

低い B♭（記譜）からハイ F♯ までの標準運指を収録。よく使う代替運指（F♯ の右手薬指キー、B♭ の 1&1、サイド C、フロント F）はヒントとして併記している。

高音域は次のとおり（一般的なチャートに準拠）。

| 記譜音 | 運指 |
| --- | --- |
| ハイ D | オクターブ＋パーム D |
| ハイ E♭ | オクターブ＋パーム D・E♭ |
| ハイ E | オクターブ＋パーム D・E♭＋サイド E |
| ハイ F | オクターブ＋パーム D・E♭・F |
| ハイ F♯ | 上記＋ハイ F♯ キー（フロント F 系の代替あり） |

ハイ E・F はメーカーや個体、教える人によって「サイド E キーを足す／足さない」の流儀がある。息とアンブシュアで当たるなら、慣れた方でよい。

## 動かす

公開版：<https://gmgngnm.github.io/saxchord/>（マイクを使うので HTTPS が要る。GitHub Pages ならそのまま使える）

手元で動かすとき：

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

`file://` で直接開いてもクイズと運指図は動くが、**マイク判定だけは HTTPS か localhost でないとブラウザが許可しない**。

リポジトリを丸ごとどこかに置けば、そのまま静的サイトとして動く（ビルド・依存なし）。

## テスト

`node test.mjs`（Playwright）で音楽理論・運指データ・ピッチ検出・各画面の操作を通しで検証している。
